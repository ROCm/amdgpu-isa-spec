# Contributing to amdgpu-is-specs

Thanks for your interest in contributing. As this repo contains only documentations, contribution is mainly in the form of reporting issues.

## Reporting Issues

Use [GitHub Issues](../../issues) to report any problems you find in the repo.

Please include:

- A clear description of the problem or requested behaviour
- amdgpu-isa-spec* revision
- Other relevant information

Search existing issues before opening a new one. If your report matches an open issue, add a comment there instead of filing a duplicate.
